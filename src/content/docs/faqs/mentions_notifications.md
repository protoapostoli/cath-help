---
title: How do @mentions and team notifications work?
description: Tagging staff in notes, receiving alerts, and using the Unified Mentions inbox.
---

CatholicOffice makes collaboration easy through `@mentions`:

---

## 1. Tagging Colleagues
Type `@` in any note box (Sacramental Files, Tasks, Reception Event Logs, Sick Calls) followed by a name (e.g., `@FatherJoe`, `@Maria`).

---

## 2. Notification Delivery
When tagged, the user receives:
- An immediate in-app notification header bell alert.
- An email alert with the note text and direct link.
- An unread item logged in their **Unified Mentions Dashboard** (`/my-mentions`).

---

## 3. The Unified Mentions Inbox
Visit `/my-mentions` to review all active discussions, filter by unread status, and click any item to jump straight into the relevant file.
