CatholicOffice provides a comprehensive case-management system for tracking all sacramental preparations and major parish events from initial inquiry to completion.

---

## Supported File Types

CatholicOffice includes dedicated modules for:

1. **Marriage Files (`/marriage-files`)**: Full canonical tracking, bride/groom records, liturgy planning, dispensations, and rehearsals.
2. **Baptism Files (`/baptism-files`)**: Infant and child baptisms, godparent verifications, online public parent registrations, and certificates.
3. **Quinceañera Files (`/quinceanera-files`)**: Candidate profiles, mass details, formation checklists, and coordination.
4. **Funeral Files (`/funeral-files`)**: Mortuary & cemetery coordination, family contacts, vigil/rosary/mass planning, and clergy assignments.
5. **Facility Rental Files (`/rental-files`)**: Parish hall and facility bookings, contracts, insurance compliance, security deposits, and room setup notes.

---

## Core Features Shared Across All Files

Every sacramental and event file shares a standardized interface:

### 1. Requirements & Document Checklists
- **Customizable Parish Templates**: Administrators can define default requirement checklists tailored to diocesan norms (e.g., certificates, canonical forms, prep classes, sponsor affidavits).
- **Role Assignments**: Assign requirements to specific parties (Bride/Groom, Mother/Father/Godparents, Deceased, Renter, or Joint).
- **Status & Attachments**: Track item status (**Pending**, **In Progress**, **Completed**, or **Waived**) and upload digital PDF/image copies.
- For detailed setup instructions, see the **[Setting Up Checklists & Supported Languages](/guides/sacramental_files/checklists_and_languages)** guide.

### 2. Multi-Language Support
- Parishes can add any custom **Supported Languages** (Spanish, Vietnamese, Portuguese, Tagalog, French, Polish, Latin, Bilingual) and set a parish default language.
- Select the preferred language on any case file or let parents choose on public registration forms.

### 3. Integrated Financial Ledger
- Real-time tracking of itemized fees (church donation, presider stipend, musician/cantor, cleaning deposit).
- Record payments (Cash, Check, Credit Card, Online), track partial balances, and print official parish receipts or financial statements.
- Seamlessly feeds into the centralized **Accounts Receivable Ledger**.

### 4. Collaborative Notes & @Mentions
- Staff and clergy can log progress notes, call logs, and pastoral meeting notes.
- Use `@Name` to tag other staff members or priests, instantly notifying them and linking directly to the file.

### 5. Liturgy & Schedule Coordination
- Track dates, times, and rehearsal schedules.
- Assign celebrants, concelebrants, and deacons directly to the file.

### 6. Printable Folders & Cards
- Generate customizable printouts for priests, deacons, and front desk binders with one click.
