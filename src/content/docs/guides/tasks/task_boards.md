The **Parish Tasks** module (`/tasks`) brings modern project management and collaboration tools to parish staff, ministries, and committees.

---

## Accessing Task Boards

- In the navigation bar, click **Tasks** (`/tasks`).
- Users can switch between multiple parish task boards (e.g., *Parish Administration*, *Facilities & Maintenance*, *Liturgy Planning*, *Youth Ministry*, *Fall Festival Committee*).

---

## Multi-View Task Dashboard

CatholicOffice supports four flexible visual layouts:

### 1. Board View (Kanban)
- Drag-and-drop task cards horizontally across customizable status columns (e.g., *To Do*, *In Progress*, *Waiting on Vendor*, *Completed*).

### 2. Table / List View
- A compact, spreadsheet-style list view allowing quick batch sorting, filtering by assignee, priority, or due date.

### 3. Calendar View
- Visualizes tasks across the calendar based on start and due dates to prevent scheduling bottlenecks.

### 4. Timeline / Gantt View
- Displays horizontal project duration bars for tracking multi-week milestones and long-range parish initiatives.

---

## Working with Task Cards

Clicking any card opens the rich **Task Card Detail Modal**:

### 1. Assignees & Collaboration
- Assign one or multiple staff members or ministry leaders.
- Leave comments, discussions, and tag colleagues with `@Name`.

### 2. Priority & Due Dates
- Set priorities: **Low**, **Medium**, **High**, or **Urgent**.
- Configure start dates and deadline alerts.

### 3. Sub-Tasks & Checklists
- Break complex tasks into interactive checklist items with progress bars.

### 4. Labels, Cover Images & Attachments
- Tag cards with custom color-coded labels (e.g., *Budget*, *Contractor*, *Urgent*, *Diocese*).
- Upload file attachments (PDF invoices, blueprints, contracts) and set visual card covers.

### 5. Cross-Linking to Parish Events & Files
- Link task cards directly to specific Sacramental Files, Rental Files, or Master Calendar Events.
